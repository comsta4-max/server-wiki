# 서버 위키

마크다운 문서를 정적 사이트로 변환해 GitHub Pages에 배포합니다.

## 문서 편집 (운영자)

1. GitHub에서 `docs/` 안의 `.md` 파일을 열고 연필 아이콘을 누릅니다.
2. 수정한 뒤 Commit을 누르면 잠시 후 사이트에 반영됩니다.

- 새 문서는 `docs/`에 영문 파일명으로 추가합니다. 메뉴에 자동으로 나타납니다.
- 메뉴 이름은 문서 첫 줄의 `# 제목`을 사용합니다.
- 다른 문서 링크는 `[규칙](rules.md)`처럼 씁니다.

> 저장소와 문서는 모두 공개됩니다. 비밀번호, RCON 정보, 개인 정보는 적지 마세요.

## 로컬 빌드

```bash
npm ci
npm run build
```

결과물은 `dist/`에 생성됩니다.
